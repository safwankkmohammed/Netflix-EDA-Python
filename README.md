# Netflix Exploratory Data Analysis (EDA)

## About the Project
This project focuses on exploring and analyzing the Netflix Movies and TV Shows dataset using Python. The goal is to identify content trends, patterns and insights through data analysis and visualization.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Analysis
- Data cleaning and preprocessing
- Missing value analysis
- Movies vs TV Shows distribution
- Country-wise content analysis
- Year-wise release trends
- Genre analysis
- Data visualization

## Project Files
- `.ipynb` – Jupyter Notebook containing the complete analysis
- `.pdf` – Project documentation
- `.pptx` – Project presentation
